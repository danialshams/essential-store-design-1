# Essential Store — طراحی فروشگاهی شماره ۱

فروشگاه واقعی **Next.js 16 + React 19 + TypeScript** با طراحی مینیمال سفید و آبی، RTL و فارسی؛ مطابق ماکاپ تأییدشده. این پروژه از مخزن پنل مدیریت مستقل است و برای دریافت یک ریپوی GitHub و Vercel مستقل آماده شده است.

## صفحات
- `/` خانه: هدر، جست‌وجو، بنر، دسته‌بندی‌ها، پرفروش‌ها، پیشنهادها، مزایا، فوتر
- `/products` همه محصولات: جست‌وجو، فیلتر دسته و قیمت، موجودی، مرتب‌سازی، فیلتر موبایل
- `/category/[slug]` دسته‌بندی‌ها
- `/product/[slug]` جزئیات محصول: انتخاب رنگ/سایز، موجودی، تعداد، مشخصات، محصولات مرتبط، علاقه‌مندی
- `/cart` سبد خرید: افزودن/حذف/تعداد، جمع و ارسال
- `/checkout` تسویه‌حساب: فرم خریدار و آدرس، روش دریافت، کد تخفیف **WELCOME10** (صرفاً دمو)
- `/checkout/success` رسید *آزمایشی* و بدون پرداخت
- `/account` سفارش‌های دمو و علاقه‌مندی‌ها؛ **ورود واقعی هنوز متصل نیست**
- `/info/about`, `/info/contact`, `/info/faq`, `/info/terms`, `/info/shipping`, `/info/privacy`
- `/api/catalog` کاتالوگ عمومی GET فقط خواندنی

## راه‌اندازی

```bash
npm install
npm run dev
```

سایت در http://localhost:3000 بالا می‌آید. نیاز به دیتابیس برای **نمایش نسخه دمو** ندارد. سازگار با Node.js 22 به بالا.

برای تست:

```bash
npm run test
npm run typecheck
npm run build
```

## اتصال آینده به پنل مشترک

در هر سایت مشتری، مسیر API خواندنی فروشگاه (`/api/store/catalog`) از پنل اختصاصی خودش می‌تواند در متغیر `STOREFRONT_CATALOG_URL` تعریف شود. آداپتر آن در `src/lib/catalog.ts` آماده است. **توجه:** صفحات فعلی برای دمو از کاتالوگ محلی استفاده می‌کنند؛ اتصال کاتالوگ پویا به همه صفحات و پیاده‌سازی همگام‌سازی سفارش هنوز کار تکمیلی است.

## وضعیت مهم

- **پرداخت، احراز هویت، ذخیره سفارش در سرور، رزرو موجودی، اتصال ارسال و صدور فاکتور واقعی هنوز پیاده‌سازی نشده‌اند.** دکمه تسویه‌حساب فقط یک سفارش موقت داخل Local Storage مرورگر می‌سازد و به‌وضوح آن را «نمایشی» معرفی می‌کند. بنابراین این پروژه **برای فروش واقعی و دریافت وجه آماده نیست**.
- قیمت‌ها **همه تومان** هستند؛ انتخاب واحد پول ندارد.
- عکس‌های داخل `public/images` برش‌های بهینه‌شده از ماکاپ دموی همین پروژه‌اند؛ از اطلاعات/تصاویر مشتری واقعی استفاده نشده.
- متن سیاست‌ها و اطلاعات تماس نمونه‌اند و پیش از تحویل عملیاتی باید بازنویسی شوند.
- اطلاعات دمو در مرورگر باقی می‌مانند؛ برای پاک‌کردن، داده‌های محلی سایت را حذف کنید.

## انتشار Vercel

1. یک مخزن **Public** به‌نام `essential-store-design-1` در GitHub بسازید؛ گزینه‌های README، .gitignore و License را در ساخت اولیه خالی بگذارید.
2. فایل‌های همین پروژه را در مخزن قرار دهید (فایل‌های `.env`، `node_modules` و `.next` را commit نکنید).
3. پروژه Vercel جداگانه بسازید و GitHub repository را به آن وصل کنید. Framework = Next.js، Root Directory = `.`.
4. اگر قصد دارید کاتالوگ را از پنل مشترک بخوانید، بعداً `STOREFRONT_CATALOG_URL` را در Environment Variables بگذارید. فعلاً بدون آن کل UI روی داده‌های نمونه اجرا می‌شود.

سایت مشتری از نظر هاست و دیتابیس باید مستقل از دیگر مشتریان بماند.
